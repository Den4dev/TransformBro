TransformBro 1.1.0 — конвертер файлов
===================================

Что это
-------
Одно окно, в которое можно бросить файлы и получить их в другом формате.
Работает без интернета, офис не обязателен (если он есть — TransformBro умеет
конвертировать .doc в .docx и PDF с вёрсткой через него).

Поддерживается
--------------
Изображения: JPG, JPEG, PNG, WEBP, BMP, GIF, TIFF, ICO, AVIF
  → конвертация в WEBP / PNG / JPG / BMP / TIFF / ICO, сжатие для Web,
    уменьшение до 1920 и 1080 px, удаление EXIF/GPS.

PDF: извлечение текста, экспорт страниц в PNG.

Документы: DOC, DOCX, DOCM, ODT, RTF, HTML
  → извлечение текста; при наличии MS Word — в DOCX и PDF с вёрсткой.

Текст: TXT, MD, CSV, JSON, LOG, XML, SRT, INI, YAML, CFG, NFO, TEX
  → PDF, DOCX, HTML (кириллица сохраняется).

Видео: MP4, MKV, AVI, MOV, WEBM, WMV, M4V, FLV, MPG, MPEG, TS, MTS, M2TS,
       3GP, OGV, VOB, F4V
  → извлечение аудио (MP3, WAV, FLAC, M4A, OGG, OPUS, AAC), сжатие в MP4
    (H.264), в AVI, в WEBM (VP9), в MKV без перекодирования, уменьшение до
    720p / 480p, GIF, покадровый экспорт в PNG.

Аудио: MP3, WAV, FLAC, OGG, M4A, AAC, OPUS, WMA, AIFF, AMR, AC3, MKA, ALAC,
       APE, WV
  → конвертация между этими форматами и выравнивание громкости (Loudnorm).

Как установить
--------------
Вариант 1 — установщик (рекомендуется):
  1. Скачать TransformBro-1.1.0-Setup.exe со страницы релизов.
  2. Запустить. Windows может показать предупреждение «Неизвестный издатель» —
     это потому, что сборка не подписана сертификатом: нажмите
     «Подробнее» → «Выполнить в любом случае».
  3. Установка идёт в ваш профиль (C:\Users\<вы>\AppData\Local\Programs\TransformBro),
     права администратора не нужны.
  4. Ярлык появится в меню «Пуск» → TransformBro и, если хотите, на рабочем столе.
  5. Удаление: «Параметры» → «Приложения» → TransformBro, либо
     Пуск → TransformBro → Удалить.

Вариант 2 — portable (без установки):
  1. Скачать TransformBro-1.1.0-win64.zip (с FFmpeg) или TransformBro-1.1.0-win64-lite.zip
     (без него: только изображения, PDF, документы и текст).
  2. Распаковать в любую папку (например C:\Tools\TransformBro).
  3. Запустить TransformBro.exe. Всё, включая FFmpeg, уже внутри папки.
  4. Можно так же просто удалить папку.

Как пользоваться
----------------
· Перетащить файлы или целую папку в окно (папка раскрывается, скрытые файлы
  пропускаются, максимум 500 файлов за раз).
· Либо нажать на пунктирную зону и выбрать файлы.
· Для каждого файла выбрать действие в выпадающем списке, затем
  «Конвертировать» или «Обработать всё».
· Готовый файл кладётся рядом с исходником с суффиксом (_webp, _audio, _720p
  и т. п.). Ничего не перезаписывается: если такое имя занято, добавляется
  _1, _2 и т. д.
· Кнопка «Открыть результат» открывает папку с результатом.
· TransformBro можно назначить программой по умолчанию: файлы, переданные как
  аргументы, сразу попадают в очередь.

Если что-то не работает
-----------------------
· В шапке горит «FFmpeg не найден» → ffmpeg.exe должен лежать рядом с
  TransformBro.exe (в установщике и portable-архиве он есть).
· Нет действий у .doc → нужен MS Word для конвертации с вёрсткой; извлечение
  текста работает и без Word.
· Файл помечен «без обработчика» → такое расширение пока не поддерживается.
